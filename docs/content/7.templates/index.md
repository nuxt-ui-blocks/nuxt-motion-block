Each template is a full page rather than a snippet. The animations belong to the sections they ship in, and the code maps to a file you can lift into your own project. Copy one as a starting point, or take a look at [Blocks](/blocks) if you only want a single section.

## Available Templates

- [Basic Landing Page](/templates/basic-landing-page) — the baseline: a hero, a features grid and the footer, with animation used where it earns its place.
- [SaaS Landing Page](/templates/saas-landing-page) — pricing, social proof and product shots for a product with a trial.
- [E-commerce Landing Page](/templates/ecommerce-landing-page) — product showcases arranged around a promotion, with animated banners and category grids.
- [Creative Agency Landing Page](/templates/creative-agency-landing-page) — a portfolio-first layout: kinetic type, image reveals and work front and center.

## How to use

Copy the template into a page in your Nuxt app and register it in the routes, then swap the content and the design tokens. The animations read the same tokens as the rest of the kit, so changing your Nuxt UI palette repaints the whole page.
