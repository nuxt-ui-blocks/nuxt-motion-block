title: Blocks
description: Twenty-one ready-made sections — hero, pricing, dashboards, portfolios — each wired with motion.
---

Blocks are complete page sections, not primitives: each one is a page you can drop into a Nuxt app and adjust to your tokens. They are built from the same components documented here, so the motion reads the same everywhere.

## Blog

- [Article Page](/blocks/blog/article-page) — featured image, author byline, table of contents and related articles.
- [Blog Listing](/blocks/blog/blog-listing) — filterable grid of recent posts with staggered entrances.

## Dashboard Components

- [Analytics Dashboard](/blocks/dashboard-components/analytics-dashboard) — KPI cards, a chart and a trend list on one board.
- [User Management](/blocks/dashboard-components/user-management) — table with search, row actions and animated state changes.

## E-commerce

- [Product Grid](/blocks/e-commerce/product-grid) — responsive grid with animated filters and quick add.
- [Shopping Cart](/blocks/e-commerce/shopping-cart) — a slide-in cart with animated line items and totals.

## Landing Page

- [Feature Showcase](/blocks/landing-page/feature-showcase) — feature wall with staggered reveals and alternating media.
- [Testimonial Carousel](/blocks/landing-page/testimonial-carousel) — reviews on a loop, with portraits and metric callouts.

## Portfolio

- [Case Study](/blocks/portfolio/case-study) — project breakdown with hero, gallery and outcomes.
- [Project Gallery](/blocks/portfolio/project-gallery) — filterable gallery with layout animations between grid states.

## Hero Sections

## Navigation

- [Modern Navbar](/blocks/navigation/modern-navbar) — responsive navbar with dropdowns and a scrolled state.

## Features

## Pricing

## Footers

## Featured Components

- [Animated Gradient](/blocks/featured-components/animated-gradient) — gradient animation behind content.
- [Animated Spotlight](/blocks/featured-components/animated-spotlight) — interactive spotlight that tracks the pointer.
- [Ripple Effect](/blocks/featured-components/ripple-effect) — expanding ripple for backgrounds.

## How to use

Copy the code for a block into your own page and adjust the content, then theme it through your Nuxt UI tokens. Every block works standalone; combine them into a page with [Templates](/templates) as a reference.
