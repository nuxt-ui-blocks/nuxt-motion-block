---
title: Noise Texture
description: A film-grain overlay generated by a single SVG turbulence filter.
---

Noise Texture paints grain with one `feTurbulence` node. The filter generates fractal noise, desaturates it with a `saturate(0)` matrix, then scales every channel with the same linear transfer, which sets the contrast without tinting the result. The output fills one `rect`, so the whole overlay is a single paint with no image to download.

Because the grain comes from a filter rather than a texture image, it stays sharp at any size and its character is fully described by four numbers. The element sits at `absolute inset-0` behind the content, and fades to `opacity-75` in dark mode where grain would otherwise disappear.

## Props

::component-props
  ::component-prop{name="frequency" type="number" default="0.4"}
  `baseFrequency` for the turbulence. Higher values give finer grain; lower values give soft, cloudy blotches.
  ::

  ::component-prop{name="octaves" type="number" default="6"}
  `numOctaves` for the turbulence. More octaves add detail at smaller scales and cost more to render.
  ::

  ::component-prop{name="slope" type="number" default="0.15"}
  Linear slope applied to each channel after desaturation, which is what sets the contrast.
  ::

  ::component-prop{name="noiseOpacity" type="number" default="0.6"}
  Opacity of the filled noise layer.
  ::

  ::component-prop{name="class" type="string" default="''"}
  CSS classes for the `<svg>`. The element is positioned to fill its parent, so give the parent a height.
  ::
::

## Accessibility

The `<svg>` is `aria-hidden` and `pointer-events-none`, so the grain is never announced and never blocks a pointer. It is pure texture — a masked overlay is the usual way to keep it away from text you still need to read.
