## Prerequisites

Nuxt Motion Block requires:

- [Nuxt](https://nuxt.com) ^4.0.0
- [@nuxt/ui](https://ui.nuxt.com) >=4.11.2
- [motion-v](https://motion.dev) >=2.4.4

`@nuxt/ui` and `motion-v` are installed automatically when you add the module with `nuxi module add`; if you add the module by hand, install them yourself.

## Installation

Install Nuxt Motion Block with one command — pick your package manager, or open the **Agents** tab for a ready-to-paste prompt for AI coding agents:

::install-command
::

Or let Nuxt do it for you:

```bash
npx nuxi module add nuxt-motion-block
```

## Adding the Module

The command above registers the module for you. If you installed it manually, add it to `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    'motion-v/nuxt',
    'nuxt-motion-block'
  ]
})
```

That's it. Every component is auto-registered with the `M` prefix, and the CSS is already included.
