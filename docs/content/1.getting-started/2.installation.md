## Prerequisites

Nuxt Motion Block requires the following peer dependencies:

- [@nuxt/ui](https://ui.nuxt.com) >=4.11.2
- [motion-v](https://motion.dev) >=2.4.4

These dependencies are installed automatically when you add the module.

## Installation

Install Nuxt Motion Block with one command:

::code-group
  ```bash [npm]
  npm install nuxt-motion-block
  ```
  ```bash [yarn]
  yarn add nuxt-motion-block
  ```
  ```bash [pnpm]
  pnpm add nuxt-motion-block
  ```
  ```bash [bun]
  bun add nuxt-motion-block
  ```
::

Or let Nuxt do it for you:

```bash
npx nuxi module add nuxt-motion-block
```

## Adding the Module

The command above registers the module for you. If you installed it manually, add it to `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    'motion-v/nuxt',
    'nuxt-motion-block'
  ]
})
```

That's it. Every component is auto-registered with the `M` prefix, and the CSS is already included.
